# BPL Dream Team Template

A dynamic, highly responsive, and interactive **Cricket Fantasy Team Selection Dashboard** built using React, Tailwind CSS, and DaisyUI. Craft your ultimate Bangladesh Premier League (BPL) squad, manage coin/budget limitations, and handle player auctions seamlessly with real time state updates.

## About the Project

BPL Dream is a sports centric web application designed to simulate a real world player drafting and squad building experience. Built as a single page application using React, it features a fluid interactive system where users can claim free credits, browse a dynamic roster of world class athletes, and purchase players based on custom pricing logic. The application actively tracks budget thresholds and maximum squad limits to provide a strict, gamified team building simulation.

## 🚀 Key Features

### 🪙 Interactive Coin Credit System
* Includes a dynamic "Claim Free Credit" portal that increases the user's available balance instantly with fluid structural animations.

### 🏏 Dynamic Player Marketplace
* Renders a clean grid of professional cricketer cards displaying specialized stats, bowling/batting hands, and individual bidding prices.

### 🛡️ Smart Budget & Squad Constraints
* Implements robust logical guards to prevent selecting more than the maximum allowed players or purchasing athletes exceeding the current wallet balance.
* Displays instant user alerts or toast notifications when validation rules are breached.

### 📋 Multi Tab Toggle Dashboard
* Features a seamless tab routing design to switch views effortlessly between the **Available Players Pool** and the active **Selected Squad Roster** with automated counter badges.

### 🗑️ Real Time Roster Release
* Allows users to review their final draft and easily remove/release players back into the auction pool, instantly refunding coins to the total balance.

## ⚙️ How to Run Locally

```bash
# Clone the repository
git clone [https://github.com/HSBHasib/BPL-Dream.git](https://github.com/HSBHasib/BPL-Dream.git)

# Go into the project folder
cd React-BPL-Dream-11-PJ

# Install dependencies
npm install

# Run the development server
npm run dev
```
